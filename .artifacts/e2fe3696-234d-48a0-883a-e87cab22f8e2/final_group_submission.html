1. DATABASE MANAGEMENT (DatabaseHelper.java)

This class manages the SQLite database, acting as the foundation for all data persistence in the app.

Category Name Purpose / Explanation
Constants DATABASE_NAME, DATABASE_VERSION Defines the physical file name ("StudentReminder.db") and the version for schema migration.
Constants TABLE_SCHEDULE, TABLE_SUBJECT, TABLE_REVIEW, TABLE_TODO Names of the internal storage tables for schedules, courses, study sessions, and tasks.
Constants COL_ID, COL_SUBJECT, COL_DAY, COL_START, COL_END, COL_ROOM Names of the data columns used to store specific class information.
Methods onCreate() Initializes the app by executing SQL strings to create all four data tables.
Methods insertSubject(), insertSchedule(), insertReview(), insertTodo() Validates and writes new records into the database.
Methods getAllSubjects(), getSchedulesByDay(), getTodosByReviewId() Fetches filtered lists of data from the database to display in the UI.
Methods updateTodoCompleted(), updateReview(), updateSubject() Modifies existing records in the database when a user edits an item or checks a task.
Methods deleteSubject(), deleteSchedule(), deleteReview(), deleteTodo() Permanently removes data based on its unique ID.
