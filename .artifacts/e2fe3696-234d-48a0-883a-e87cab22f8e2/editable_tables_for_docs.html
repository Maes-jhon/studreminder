1. Activities (UI Controllers)

Class Name Variables / Constants Method / Function Purpose
AddReviewActivity etSubject, etTopic, etDate, dropdownReminder, databaseHelper, editMode saveOrUpdateReview(), showDatePicker(), setupReminderDropdown() Handles the creation and editing of review sessions. It manages user input, date/time selection, and saves data to the database.
ReviewDetailsActivity recyclerTodos, todoAdapter, todoList, reviewId loadReviewDetails(), setupTabs(), showAddTodoDialog(), loadTodos() Displays specific details of a review and manages the checklist (Todo) items associated with it.
ScheduleActivity recyclerSchedule, scheduleAdapter, tvMon, tvTue, selectedDay selectDay(), loadSchedules(), setupBottomNavigation() The main dashboard for class schedules. Allows users to switch between days and see their timetable.
SubjectsActivity recyclerSubjects, adapter, subjectList, databaseHelper loadSubjects(), setupBottomNavigation() Lists all academic subjects added by the user and provides navigation to subject-specific reviews.

2. Database Management

Class Name Constants (Storage Names) Core Methods Purpose
DatabaseHelper DATABASE_NAME, TABLE_SUBJECT, TABLE_REVIEW, TABLE_TODO, COL_ID, COL_SUBJECT onCreate(), insertSubject(), getAllSchedules(), updateTodoCompleted(), deleteReview() Acts as the central data hub. It creates the physical storage tables and provides methods for Saving, Loading, Updating, and Deleting data.

3. Data Models (Blueprints)

Class Name Key Variables Methods Purpose
Subject id, subject, teacher, room, color getId(), getSubject(), getColor() Defines the structure of a course/subject entity.
Review id, subject, topic, date, time, reminder getTopic(), getDate(), getReminder() Defines the structure of a study session entity.
Todo id, reviewId, task, completed getTask(), isCompleted(), setCompleted() Defines a single checklist task within a review.

4. UI Adapters (Bridge)

Class Name Main Variables Core Methods Purpose
SubjectAdapter / TodoAdapter listData, viewHolder onCreateViewHolder(), onBindViewHolder(), updateTaskStyle() Binds the database objects to the visual list items on the screen. It handles the logic for how items look (like adding strikethroughs to completed tasks).
