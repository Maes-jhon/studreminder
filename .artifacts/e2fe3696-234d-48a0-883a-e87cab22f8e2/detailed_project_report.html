StudReminder: Full Project Components Report

Project: Student Reminder Application
Activity Type: Group Activity Submission

This document provides a comprehensive list of all classes, variables, constants, and methods used in the StudReminder project, detailing their specific roles and functionality.

1. Database Management

Handles all persistent storage using SQLite.

DatabaseHelper.java

ComponentNamePurpose
ConstantDATABASE_NAMEThe name of the SQLite file: "StudentReminder.db".
ConstantTABLE_SCHEDULE, TABLE_SUBJECT, TABLE_REVIEW, TABLE_TODOIdentifiers for the four main data tables.
MethodonCreate()Initializes the database by creating all required tables and columns.
MethodonUpgrade()Handles database schema changes when the version number increases.
MethodinsertSubject(), insertSchedule(), insertReview(), insertTodo()Methods to add new records to their respective tables.
MethodgetAllSubjects(), getSchedulesByDay(), getReviewsBySubject()Retrieve specific datasets from the database for display.
MethodupdateTodoCompleted()Specifically updates the boolean status of a task item.
MethoddeleteSubject(), deleteSchedule(), deleteReview(), deleteTodo()Methods to remove records based on their ID.

3. Data Models (POJOs)

Plain Old Java Objects used to structure data in the app's memory.

Subject, Schedule, Review, Todo

ClassKey VariablesPurpose
Subjectid, name, teacher, room, colorDefines a course/subject added by the student.
Scheduleid, subject, day, startTime, endTime, roomRepresents a specific occurrence of a class.
Reviewid, topic, date, time, reminderRepresents a planned study session.
Todoid, reviewId, task, completedA single task or checklist item inside a Review.

4. Adapters (List Logic)

Adapters act as the bridge between data models and RecyclerView UI components.

SubjectAdapter, ScheduleAdapter, ReviewAdapter, TodoAdapter

MethodPurpose

onBindViewHolder()Populates the text views and colors of a list item using the data model.
